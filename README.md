# Digital IV — Morayo & Dayo (Eventlybuilt)

    npm install
    npm run dev      # http://localhost:3000

## Deploy (Vercel)
1. Push this folder to a new GitHub repo.
2. vercel.com → Add New → Project → import the repo → Deploy. No environment variables needed.

## Edit for a new couple
- Names, dates, venues, aso-ebi prices, bank and links: the `C` block at the top of components/Invite.tsx
- Photos: replace the files in public/img (keep the same names)
- Personalised link: https://your-site.vercel.app/?to=Aunty%20Bisi
- Music (optional): add public/music.mp3, a track you have the rights to. The music button only shows when it exists.
